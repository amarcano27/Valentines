# Images Directory

Place your photos here!

## Recommended Image Names:
- `photo1.jpg` - Main photo (will appear in the question box)
- `photo2.jpg` - Second photo (will appear in a heart-shaped frame)
- `photo3.jpg` - Third photo (will appear in the gallery)

## Image Guidelines:
- **Format**: JPG, PNG, or GIF
- **Size**: Recommended max 2MB per image for fast loading
- **Dimensions**: 800x800px or larger works best
- **Orientation**: Square or portrait photos work best for the layouts

## How to Add Your Images:
1. Copy your photos into this `images/` folder
2. Name them `photo1.jpg`, `photo2.jpg`, `photo3.jpg` (or update the names in index.html)
3. Refresh your browser to see them appear!

Enjoy! 💕
